# fhs
Fakhri Hygiene Solutions Website

This repository contains the frontend site for Fakhri Hygiene Solutions, including a catalog of products with images.

Getting started:
- Prerequisites: Node.js and npm
- Install dependencies: `npm install`
- Run the app: `npm run dev`
- Build for production: `npm run build`
- View in browser after the dev server starts (the port may vary, e.g. http://localhost:3000)

Notes:
- Node modules are ignored via .gitignore; run npm install after cloning.
- The image catalog is mapped in `constants.ts` and used by the catalogue components.
